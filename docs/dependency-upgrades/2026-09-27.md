## Runtime and migration boundaries

- **Node.js:** The package declares `>=22`, CI tests with Node.js 22, and
  `action.yml` runs with Node.js 24. Keep both supported families. Node.js 26
  remains in its Current release phase, so adopting it as a new required
  baseline is deferred pending an explicit support-policy change and runner
  verification. [Node.js release schedule](https://nodejs.org/en/about/previous-releases).
- **npm:** No npm version is pinned by the project. Defer an npm 12 pin:
  npm 12's package engines require Node.js `^22.22.2 || ^24.15.0 || >=26.0.0`,
  which excludes earlier patch versions in the declared `>=22` development
  range. [npm CLI package metadata](https://www.npmjs.com/package/npm/v/12.0.0),
  [npm installation guidance](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm/).
- **Python:** Lint CI selects Python 3.14 and installs pre-commit 4.6.2.
  Python does not run the JavaScript action. Defer replacement of the
  `fix-smartquotes` hook with `sirosen/texthooks`: Python 3.14 support appears
  in texthooks' *unreleased* changelog, so released support is not yet
  verifiable. [texthooks changelog](https://github.com/sirosen/texthooks/blob/main/CHANGELOG.md),
  [texthooks releases](https://github.com/sirosen/texthooks/releases).

The scheduled/manual [runner compatibility workflow](../../.github/workflows/compatibility.yml)
owns the 18-label native-adapter sweep; its manual dispatch also runs the
seven-class no-input default-max sweep after generated-dist passes. A release
requires those runs, current-head PR CI, and review. No runner matrix or
action bundle behavior changes are included in this dependency update.
